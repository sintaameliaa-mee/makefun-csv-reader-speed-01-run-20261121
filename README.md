A fast drop-in for make.fun's csv-reader 1.0.0: reads broken CSV files
exactly as csv-reader does — quoted fields, embedded newlines, escaped
quotes, stray CRs, ragged rows — with identical `{columns, rows, errors}`
answers, at much lower CPU time. Dependency-free, Node 22.

## Run it

```sh
node main.ts
```

Reads `/input/cases.json`, writes `/output/answers.json`.
